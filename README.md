# 🍔 Food Delivery Application

A full-featured Food Delivery Backend built with **Django** and **Django REST Framework**.  
This project provides APIs for users, restaurants, orders, payments, delivery, reviews, and promotions.

---

## 🚀 Features

✅ User Authentication & Profiles  
✅ Restaurant Management  
✅ Menu & Food Items  
✅ Order Placement & Tracking  
✅ Delivery System  
✅ Payment Integration  
✅ Reviews & Ratings  
✅ Promo / Discount System  
✅ Notifications Module  

---

## 🛠 Tech Stack

- **Backend:** Django, Django REST Framework  
- **Database:** SQLite / PostgreSQL (configurable)  
- **Language:** Python  
- **API Style:** RESTful APIs
